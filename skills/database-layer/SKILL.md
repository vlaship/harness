## Preconditions
`openapi-spec` completed. OpenAPI sources generate with `mvn generate-sources`.

## Goal
Set up PostgreSQL schema management with Liquibase and create the Person entity and repository.

## Instructions

1. Create **pre-Liquibase changelog** (`app/src/main/resources/db/changelog/db.pre-changelog.sql`):
   - `CREATE SCHEMA IF NOT EXISTS sample;`
2. Create **main Liquibase changelog** (`app/src/main/resources/db/changelog/db.changelog-master.yaml`):
   - Changeset `001-create-person-table`:
     - Table `sample.person`:
       - `id` — UUID, primary key (NOT auto-generated by DB — application generates UUID v7)
       - `first_name` — VARCHAR(100), NOT NULL
       - `last_name` — VARCHAR(100), NOT NULL
       - `email` — VARCHAR(255), NOT NULL, UNIQUE
       - `birth_date` — DATE, NOT NULL
       - `phone` — VARCHAR(20), nullable
       - `created_at` — TIMESTAMP WITH TIME ZONE, NOT NULL, DEFAULT NOW()
       - `updated_at` — TIMESTAMP WITH TIME ZONE, NOT NULL, DEFAULT NOW()
       - `created_by` — VARCHAR(255), nullable
       - `modified_by` — VARCHAR(255), nullable
       - `version` — BIGINT, NOT NULL, DEFAULT 0
     - Index on `last_name`
3. Create **`package-info.java`** in every Java package created in this skill:
   ```java
   @org.jspecify.annotations.NullMarked
   package com.example.sample.entity;
   ```
   Do the same for `com.example.sample.config` and any other new packages.
4. Create **`Domain`** marker interface (`app/src/main/java/com/example/sample/entity/Domain.java`):
   - Empty interface — entities implement it for type-safety in generic code
5. Create **`Person` entity** (`app/src/main/java/com/example/sample/entity/`):
   - `@Entity`, `@Table(schema = "sample")`, `@ToString`
   - `implements Domain`
   - Lombok: `@Getter`, `@Setter`, `@NoArgsConstructor`, `@AllArgsConstructor`, `@Builder`
   - Do **NOT** use `@Data`, do **NOT** use `@EqualsAndHashCode`
   - `id` field: `UUID` type, `@Id`, no `@GeneratedValue` — generated in code via UUID v7
   - `version` field: `Long`, annotated `@Version` — Hibernate optimistic locking; never set manually; add `@Column(nullable = false)` to match the DB constraint
   - Nullable fields annotated with `@Nullable` (from `org.jspecify.annotations`):
     - `phone` — optional field
     - `createdBy`, `modifiedBy` — null for unauthenticated contexts (Liquibase, scheduled tasks)
   - All other fields are non-null by default (package is `@NullMarked`)
   - Auditing: `@CreatedDate` / `@LastModifiedDate` on `createdAt`, `updatedAt`
   - Auditing: `@CreatedBy` / `@LastModifiedBy` on `@Nullable createdBy`, `@Nullable modifiedBy` (String)
   - Use `@PrePersist` to assign `id = Generators.timeBasedEpochGenerator().generate()` if null (UUID v7)
   - Or use Java 25 `UUID.v7()` if available, otherwise `com.fasterxml.uuid:java-uuid-generator`
   - **Hand-written `equals()` and `hashCode()`** — Hibernate proxy-safe pattern:
     ```java
     @Override
     public final boolean equals(Object o) {
         if (this == o) return true;
         if (o == null) return false;
         Class<?> oEffectiveClass = o instanceof HibernateProxy p
             ? p.getHibernateLazyInitializer().getPersistentClass() : o.getClass();
         Class<?> thisEffectiveClass = this instanceof HibernateProxy p
             ? p.getHibernateLazyInitializer().getPersistentClass() : this.getClass();
         if (thisEffectiveClass != oEffectiveClass) return false;
         Person that = (Person) o;
         return getId() != null && Objects.equals(getId(), that.getId());
     }

     @Override
     public final int hashCode() {
         return this instanceof HibernateProxy p
             ? p.getHibernateLazyInitializer().getPersistentClass().hashCode()
             : getClass().hashCode();
     }
     ```
   - This pattern handles lazy-loaded proxies correctly. Both methods are `final` to prevent subclass breakage.
   - **Optimistic lock conflict**: if two requests update the same entity concurrently, Hibernate throws `ObjectOptimisticLockingFailureException`. The `GlobalExceptionHandler` (added in `rest-controller` skill) must map this to `409 Conflict` ProblemDetail.
6. Create **`PersonRepository`** extending `JpaRepository<Person, UUID>`
7. Create **`SecurityAuditorAware`** (`app/src/main/java/com/example/sample/config/`):
   - Implements `AuditorAware<String>`
   - `@Component`
   - `getCurrentAuditor()` reads username from `SecurityContextHolder`:
     ```java
     @Override
     public Optional<String> getCurrentAuditor() {
         return Optional.ofNullable(SecurityContextHolder.getContext().getAuthentication())
             .filter(Authentication::isAuthenticated)
             .filter(auth -> !(auth instanceof AnonymousAuthenticationToken))
             .map(Authentication::getName);
     }
     ```
   - Returns `Optional.empty()` for unauthenticated contexts (e.g. Liquibase startup, scheduled tasks)
8. Enable JPA Auditing: `@EnableJpaAuditing` (Spring auto-detects the `AuditorAware` bean)
9. Create **`application.yml`**:
   - Datasource: `${DB_HOST:localhost}`, `${DB_PORT:5432}`, `${DB_NAME:sampledb}`, `${DB_SCHEMA:sample}`
   - Liquibase config pointing to changelog master + pre-Liquibase schema creation
   - Default schema: `sample`
10. Create profile configs:
    - `application-local.yml` — show SQL, local dev
    - `application-test.yml` — Testcontainers-friendly
    - `application-prod.yml` — production-safe (no show SQL, connection pool)
11. Create **`docker-compose.yml`** in project root:
    - PostgreSQL 17, database `sampledb`, user/password `sample`, port `5432:5432`, named volume

## Output
- Liquibase changelogs in `app/src/main/resources/db/changelog/`
- `Domain.java`, `Person.java`, `PersonRepository.java`
- `SecurityAuditorAware.java`
- `application.yml`, `application-local.yml`, `application-test.yml`, `application-prod.yml`
- `docker-compose.yml`
